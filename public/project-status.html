Next work to close the prototype gate

Ordered from project docs
01 · Validate with real API keysOpen

Run the real-key script and visual tests on at least three briefs. Validate board quality, copy, visuals and repair behaviour.

02 · Produce real per-frame artOpen

Generate the individual assets named in each manifest. Keep character masters, poses, backgrounds and transparent props separate. Validate before render.

03 · Add missing visual lintOpen

Detect empty layers and boards with no meaningful visual. Fail before render instead of relying only on manual inspection.

04 · Complete morph and wrap passesOpen

Close the morph anchor and wrap pass items listed under P4. Re-check the editor and exported composition.

05 · Run the end-to-end acceptance flowGate

One client → drop three assets → create a 15 s brief → generate five boards → Plan all → edit text and position → render MP4. No manual JSON edits.

How the project is built

Current documented architecture
Authoring surfacesMain / Direct / Studio
Product servicesStore · planner · board planner · editor
DirectorPlan → HyperSpec JSON
CompilerValidate · compile · bake keyframes
RendererSkia frames · in-process H.264

The engine is isolated from client and LLM concerns. Rendering is deterministic at the frame level. No browser, DOM, CSS engine, LLM or network call is used at render time.
